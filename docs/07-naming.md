# Naming

## The pick: Yarn

In New Zealand a yarn is both a story and a chat with someone. Those are the two halves of the system: the tale on the box and the talk at dinner. It is also plainly an object, not a person, which matters given the rule against personas.

## Runners-up

- **Trellis:** holds the plant up until it doesn't need holding. The most honest about the fade, but a bit garden-centre.
- **Once:** as in "once upon a time", and as in you only need it once. Short, but hard to search for.
- **Chapter:** one a night, and chapters end. Sensible, though crowded as a brand.
- **Ractor:** a nod to the book that names the human role. Lovely for people who've read it, baffling for everyone else.

## Names to avoid

- **Primer:** taken several times over.
- **Miranda or Nell:** tempting tributes, but a human name turns the book into a being.
- **Anything with "AI", "buddy" or "pal":** it describes the opposite product.

## Not yet checked

- Trademarks and domains for any of these.
- "Yarn" is already a JavaScript package manager. Parents won't care, but developers searching for the project will hit it.
